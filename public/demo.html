📡 API Endpoints

Access the CRM via REST API:

  • GET /api/crm/dashboard - Dashboard statistics
  • GET /api/crm/contacts - List all contacts
  • GET /api/crm/deals - List all deals
  • GET /api/crm/inventory - List inventory items
  • POST /api/crm/contacts/score - AI lead scoring
  • POST /api/crm/deals/:id/analyze - AI deal analysis
  • POST /api/crm/inventory/predict - AI inventory predictions
